# Моделирование переходного периода в правоприменительной практике

- **Магистрант:** Лихошерстов Павел Евгеньевич
- **Научный руководитель:** Ковальчук Сергей Валерьевич, к.т.н., доцент факультета технологий искусственного интеллекта, Университет ИТМО
- **Научный консультант:** Береговенко Илья Игоревич
- **Тема:** Моделирование переходного периода в правоприменительной практике

## Цель

Построить предсказательную модель динамики судебной практики после изменения нормы, оценивающую длительность переходного периода и траекторию выхода на новый устойчивый режим, и проверить её на серии изменений норм.

## План работы на 2 года

| Семестр | Результат |
|---|---|
| Осень 2026 | Сбор данных и выбор юрисдикции, формализация показателей практики, обзор моделей |
| Весна 2027 | Базовые модели на 1–2 изменениях норм, публикация (ВАК К1 или Scopus) |
| Осень 2027 | Учёт роли судей и судов, расширение на серию изменений норм |
| Весна 2028 | Итоговая модель, тестирование сценариев реформ, ВКР |
